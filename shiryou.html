0　そもそもの基本

プログラムとは

プログラムとは、コンピューターへの命令を順番に書いた文章です。料理のレシピに近いものです。レシピは「卵を割る、かき混ぜる、焼く」と順番に書きます。プログラムも「この文字を表示する、ボタンが押されたらこれをする」と順番に書きます。コンピューターは、書かれたとおりに、書かれた順番で、疑わずに実行します。

そのため、人間なら読み流せる打ち間違い(記号一つの抜けなど)でも、コンピューターは動けなくなります。打ち間違いは誰でもします。間違いを見つけて直すことも、プログラミングの大事な仕事の一部です。

ソースコードとは

人間が書いた命令の文章のことをソースコード(source code)と呼びます。「ソース」は元(もと)、「コード」は記号の並びという意味です。つまり「プログラムの元になる文章」です。「ITエンジニアが書くようなソースコード」とは、この文章のことです。特別な魔法の文字ではなく、メモ帳で書ける普通の文字です。

ファイルと拡張子

ファイルは、パソコンの中の「1枚の書類」です。ファイル名の最後にある「.(ドット)から後ろ」を拡張子(かくちょうし)と呼び、ファイルの種類を表します。

ファイル名拡張子種類
memo.txt.txtただの文章(メモ帳で開く)
photo.jpg.jpg写真
index.html.htmlWeb ページ(ブラウザで開くと画面になる)

今回使う index.html は、中身は文章ですが、拡張子が .html なので、ダブルクリックするとブラウザが「Web ページだ」と判断して開きます。メモ帳で開けば、中の文章(ソースコード)が見えます。同じファイルを、メモ帳は「文章」として、ブラウザは「画面」として見せるのです。

拡張子が見えない場合は、エクスプローラーの上の「表示」→「表示」→「ファイル名拡張子」にチェックを入れると表示されます。

1　全体像

HTML とは

HTMLは HyperText Markup Language(ハイパーテキスト・マークアップ・ランゲージ)の略です。

単語意味ここでの意味あい
Hyper Textハイパーテキストリンクで別のページへ飛べる文章
Markup目印を付けること文章に「ここは見出し」「ここは段落」と印を付ける
Language言語決まりごとのある書き方

つまり HTML は「文章に目印を付けて、ブラウザにこれは何の部分かを教えるための書き方」です。家でいえば柱と壁にあたり、画面の骨組みを作ります。

JavaScript とは

JavaScriptは、画面に動きを付けるための言語です。ボタンを押したら文字が変わる、入力した内容が一覧に追加される、といった動きを作ります。家でいえば電気の配線で、スイッチを押すと明かりがつく仕組みにあたります。

注意:名前が似ている「Java」とは、まったく別の言語です。「インド」と「インドネシア」くらい違います。名前が似ているのは歴史的な経緯で、気にする必要はありません。

ブラウザとは

ブラウザ(Edge、Chrome など)は、HTML と JavaScript を読んで、画面に表示して動かすアプリです。私たちが書くのは「楽譜」で、ブラウザは「演奏する人」です。

三つの関係

あなたが書く(メモ帳)
   ↓ index.html に保存
ブラウザが読む
   ├ HTML の部分       → 画面の骨組みを作る
   └ JavaScript の部分 → 画面に動きを付ける

この資料では、HTML と JavaScript を index.html という一つのファイルに書きます。

作業の流れ(これを何度も繰り返します)

  1. メモ帳で書く
  2. Ctrl + S で保存する
  3. ブラウザで F5 を押して更新する
  4. 結果を見る。思ったとおりでなければ、1 に戻る

なぜ保存が必要か:ブラウザが読むのは「保存されたファイル」です。メモ帳に打っただけでは、ブラウザからは見えません。書いたら保存、保存したら F5、が基本の動作です。

2　作業の準備

メモ帳で開く

  1. エクスプローラーで作業フォルダを開きます。
  2. index.html を右クリックします。
  3. 「プログラムから開く」を選びます。
  4. 「メモ帳」を選びます。

なぜ右クリックから開くのか:ダブルクリックだと、ブラウザが開いて「画面」として表示されます。書き込みたいときは、メモ帳で「文章」として開く必要があります。

UTF-8 で保存する

文字コードとは、文字をコンピューターが扱える数字に置き換える約束事です。「あ」は何番、「A」は何番、と番号表のようなものがあります。この番号表には種類があり、書いたときと読むときで種類が食い違うと、「縺薙ｓ」のような意味のない文字になります。これを文字化けと呼びます。

これを防ぐため、番号表を UTF-8(ユーティーエフ・エイト)に統一します。世界中の文字を扱え、Web ではほぼ標準です。

  1. メモ帳で「ファイル」→「名前を付けて保存」を選びます。
  2. 下にある「文字コード」を「UTF-8」にします。「UTF-8 (BOM付き)」は選びません。
  3. 「保存」を押します。上書きの確認が出たら「はい」を選びます(中身は空なので問題ありません)。

2回目からは Ctrl + S だけで、同じ設定のまま保存されます。

3　まず HTML だけを書く

いきなり JavaScript を書く前に、HTML だけで画面を作ってみます。ここで「タグ」の考え方を理解すれば、次の章がずっと読みやすくなります。

やってみる

index.html に、次の1行だけを打って保存し、ブラウザで開いてみてください。(この後、中身は書き換えます。)

<p>こんにちは</p>

画面に「こんにちは」と出ます。<p> や </p> は画面に出ません。これは命令であって、表示する文字ではないからです。

タグとは

< と > で囲まれた部分をタグと呼びます。荷物に貼る「ラベル」のようなものです。「この中身は割れ物です」というラベルが荷物の扱いを決めるように、タグは「この中身は段落です」とブラウザに伝えます。

<p>  こんにちは  </p>
 ↑        ↑         ↑
開始タグ   中身     終了タグ
  • 開始タグ <p>:ここから始まります、という印
  • 終了タグ </p>:ここで終わりです、という印。スラッシュ / が付くのが目印です
  • この三つ(開始タグ、中身、終了タグ)をまとめて要素(ようそ)と呼びます

なぜ「p」で囲うのか

p は paragraph(パラグラフ、段落)の頭文字です。<p>…</p> で囲むと、「この文章は一つの段落だ」とブラウザに伝わります。

囲わなかったらどうなるか:文章だけを書いても表示はされます。ただ、ブラウザは「何の文章か」を知らないので、段落としての余白も付きません。HTML は「中身に意味を与える」ものなので、中身は必ず何かのタグで囲うのが基本です。

タグは p だけではありません。よく使うものを挙げます。

タグ由来意味
<p>paragraph段落
<h1>heading 1一番大きい見出し
<button>buttonボタン
<input>input入力欄
<ul> <li>unordered list / list item箇条書きの全体 / その1項目

ToDo リストを作る段階で、button、input、ul、li を実際に使います。今は覚えなくて大丈夫です。

タグの入れ子

タグの中にタグを入れられます。これを入れ子と呼びます。箱の中に小さい箱を入れるイメージです。

<ul>
  <li>牛乳</li>
  <li>パン</li>
</ul>

内側の li を2つとも閉じてから、外側の ul を閉じます。先に開いたものを、最後に閉じるのが決まりです。li が少し右にずれて書いてあるのはインデント(字下げ)と言い、入れ子の関係を人間が見やすくするためのものです。ブラウザは字下げを気にしませんが、あなたが後で読むときに大きく助かります。

属性とは

開始タグの中に、追加の情報を書けます。これを属性(ぞくせい)と呼びます。

<p id="message">こんにちは</p>
   ↑
  属性名="属性の値"

属性は、荷物に貼る「宛名シール」のようなものです。id は identifier(識別するもの)の略で、要素に付ける名前です。次の章で JavaScript が「あの段落を書き換えて」と指名するときに、この名前を使います。

注意:同じページの中で、同じ id を2つ以上の要素に付けてはいけません。名前が重複して、どれを指すか分からなくなるからです。

ページ全体の骨組み

Web ページには、決まった「型」があります。<p> 1行だけでもブラウザは表示してくれますが、正式には次のように書きます。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのページ</title>
</head>
<body>
  ここに画面に出す内容を書く
</body>
</html>
部分意味
<!DOCTYPE html>「このファイルは HTML で書かれています」という宣言。ファイルの1行目に必ず書きます。
<html lang="ja">…</html>ページ全体を囲む一番外側の箱。lang="ja" は「日本語のページです」という属性です。
<head>…</head>頭(head)。画面には出ない、ページの情報を入れる場所。名札のようなものです。
<meta charset="UTF-8">「この文章の文字コードは UTF-8 です」とブラウザに伝えます。第2章で保存時に選んだ UTF-8 と、ここで同じ約束をそろえています。終了タグはありません。
<title>…</title>ブラウザのタブに表示される名前。
<body>…</body>体(body)。画面に表示される内容を入れる場所。

この中で、画面に見えるのは body の中身だけです。

4　最初のプログラム

いよいよ JavaScript を足します。index.html の中身をすべて消して、次の内容に置き換えてください。コピーして貼ってもかまいません。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのページ</title>
</head>
<body>
  <p id="message"></p>
  <script>
    document.getElementById("message").textContent = "こんにちは";
  </script>
</body>
</html>

保存して、ブラウザで開く(または F5 で更新する)と、画面に「こんにちは」と出ます。

HTML の部分(第3章の復習)

骨組みは前章と同じです。違うのは body の中身だけです。

<p id="message"></p>

中身が空の段落を作り、message(メッセージ)という名前を付けています。画面に出す文字を、あえて HTML には書いていません。JavaScript に書き込ませる「空の箱」を用意しているのです。

JavaScript の部分

<script>
  document.getElementById("message").textContent = "こんにちは";
</script>

<script>…</script> の間は、HTML ではなく JavaScript として読まれます。script は「台本」という意味です。ここに書いた命令を、ブラウザが上から順に実行します。

中心の1行を、細かく分けて読みます。

document . getElementById ( "message" ) . textContent = "こんにちは" ;
部分意味
document「このページ全体」を指す言葉。JavaScript の側で、最初から使えるように用意されています。
.(ドット)「の」と読むと分かりやすい記号。document.getElementById は「ページの、getElementById」。
getElementById「ID で要素を取ってくる」という意味の英語(get Element By Id)。要素を探して手に取る命令です。
("message")カッコの中に、探したい名前を渡します。HTML で付けた id="message" と、一字一句同じにします。
textContent要素の「中の文字」。直訳すると「文章の中身」です。
=数学の「等しい」ではなく、右の値を左に入れる(代入)という意味です。
"こんにちは"入れる文字。
;(セミコロン)「この命令はここで終わり」という印。日本語の句点「。」にあたります。

全体を日本語にすると、こうなります。

「このページの中から、message という名前の要素を探し、その中の文字を『こんにちは』にする」

なぜ「こんにちは」を引用符で囲うのか

"(ダブルクォーテーション)で囲んだものは、ただの文字として扱われます。囲まないと、JavaScript は「こんにちは」を命令や変数の名前だと思って探し始め、見つからずにエラーになります。「文字として扱ってほしいものは、" で囲う」と覚えてください。このように引用符で囲った文字を文字列と呼びます。

また、引用符は半角の " を使います。全角の「”」だと動きません。日本語入力のままだと全角になりやすいので、コードを打つときは半角英数に切り替えてください。

なぜ script は body の最後に書くのか

ブラウザは、ファイルを上から順に読みます。<script> が <p id="message"> より前にあると、「message」の箱がまだ読み込まれておらず、探しても見つかりません。だから、先に箱を作り、後から JavaScript で触る順番にします。

半角スペースと改行、インデント

HTML も JavaScript も、行頭の空白は動作に影響しません。行頭を2文字ずらしているのは、入れ子の関係を人間が読みやすくするためです。ただし、< や " や ; など記号は、1文字でも欠けると動きません。大文字と小文字も区別されます(getElementById を getelementbyid と書くとエラーになります)。

確認すること

  1. Ctrl + S で保存した
  2. index.html をブラウザで開いた(または F5 で更新した)
  3. 画面に「こんにちは」と出た
  4. ブラウザのタブに「はじめてのページ」と出た

ちょっと試す(壊してみる)

理解を深めるために、わざと変えてみましょう。変えたら保存して F5 を押し、何が起きるかを見てください。

  • "こんにちは" を "おはよう" に変える
  • getElementById("message") の message を massage に変える(HTML の名前と食い違わせる)→ 何も出なくなります。F12 でコンソールを見てください

確認が終わったら元に戻してください。壊して直す経験は、一番よい勉強になります。

動かないとき

慌てて全部書き直す必要はありません。次の手順で、エラーの文章を読みます。

  1. ブラウザで F12 キーを押す(開発者ツールが開きます)
  2. 上の方にある「コンソール」タブを押す
  3. 赤い文字が出ていれば、それがエラーです

エラー文の読み方

Uncaught TypeError: Cannot set properties of null (setting 'textContent')
    at index.html:10
  • 1行目の前半(TypeError など)は、エラーの種類です。
  • 1行目の後半が、何が起きたかの説明です。上の例は「null(何もない)に対して、textContent は書き込めない」という意味で、探した箱が見つからなかったことを表します。
  • 末尾の index.html:10 は「index.html の10行目」です。メモ帳でその行を見ます。

エラー文が英語でも、全部を読む必要はありません。「種類」と「何行目か」の二つが分かれば、探す場所を絞れます。分からなければ、赤い文字をそのまま私に貼ってください。一緒に原因を探します。

画面に何も出ないとき、よくある原因

原因確認すること
保存していないメモ帳のタイトルに * が付いていないか
更新していないブラウザで F5 を押したか
名前の食い違いHTML の id="message" と、JavaScript の "message" が一字一句同じか
全角の記号" や ( や ; が半角か
閉じ忘れ</p>、</script> など、終了タグがあるか
大文字と小文字getElementById の大文字 E、B、I が合っているか
文字化けUTF-8 で保存したか。<meta charset="UTF-8"> があるか
